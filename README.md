**Health Equity Evidence Centre Primary Care Prototype Datapacks**

This repository holds data and code to generate a package of prototype datapacks describing NHS primary care data by Integrated Care Board region for England.

The datapacks summarise data highlighting inequalities in workforce, funding, quality of care measures and appointment demand.

To replicate the analysis and generate the prototype datapacks you will need to:

- Download and extract each folder of raw data (_to follow_)
- Download the GP practice deprivation lookup
- Run the hecc_script_v3.0 code
- This generates the final_data.csv dataset
- Download the Rmd file and template Powerpoint presentation file
- Download and run the render script to generate a series of regional datapacks for each Integrated Care Board region
